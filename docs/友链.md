### Model

```go
type FriendLink struct {
    ID          int64     `json:"id"`
    Name        string    `json:"name"`
    Avatar      string    `json:"avatar"`
    URL         string    `json:"url"`
    Description string    `json:"description"`
    Status      int       `json:"status"`
    Sort        int       `json:"sort"`
    CreatedAt   time.Time `json:"created_at"`
    UpdatedAt   time.Time `json:"updated_at"`
}
```

然后定义一个创建 DTO：

```go
type CreateFriendLinkRequest struct {
    Name        string `json:"name" binding:"required"`
    Avatar      string `json:"avatar"`
    URL         string `json:"url" binding:"required,url"`
    Description string `json:"description"`
}
```

## Handler

大概就是这个思路：

```go
func (h *FriendHandler) Create(c *gin.Context) {
    var req CreateFriendLinkRequest

    if err := c.ShouldBindJSON(&req); err != nil {
        c.JSON(400, gin.H{
            "message": "参数错误",
        })
        return
    }

    friend, err := h.service.Create(c.Request.Context(), req)
    if err != nil {
        c.JSON(500, gin.H{
            "message": "创建失败",
        })
        return
    }

    c.JSON(200, friend)
}
```

这里你重点看懂：

```text
ShouldBindJSON
      ↓
Request DTO
      ↓
Service
      ↓
JSON Response
```

**不要先追求写得多漂亮。**

## Service

```go
func (s *FriendService) Create(
    ctx context.Context,
    req CreateFriendLinkRequest,
) (*FriendLink, error) {

    friend := &FriendLink{
        Name:        req.Name,
        Avatar:      req.Avatar,
        URL:         req.URL,
        Description: req.Description,
        Status:      1,
    }

    return s.repo.Create(ctx, friend)
}
```

你会发现其实和 Java 很像：

```text
Java

Controller
   ↓
Service
   ↓
Mapper

Go

Handler
   ↓
Service
   ↓
Repository
```

## Repository

如果你项目使用 GORM，大概：

```go
func (r *FriendRepository) Create(
    ctx context.Context,
    friend *FriendLink,
) (*FriendLink, error) {

    err := r.db.WithContext(ctx).
        Create(friend).Error

    return friend, err
}
```

如果你项目不是 GORM，而是 `sqlx` / 原生 SQL / Ent，就**不要照我这个写**。

你应该直接模仿项目里现有的 Article Repository。

# 你现在最适合的写法

因为你说**“增加功能不会改”**，所以我反而不建议你直接把上面代码复制进去。

你先在项目里找到：

```text
文章列表
文章详情
文章新增
```

然后告诉我：

> **“这是我的项目目录 + Article 相关代码，我想照着它加 FriendLink。”**

你把**项目目录截图或者相关 Go 文件贴给我**，我可以直接按照你现在这个项目的实际架构，告诉你：

```text
① 哪几个文件要新增
② 哪几个文件要修改
③ 每个文件为什么这么改
④ 哪些代码可以直接仿照 Article
⑤ 最后怎么用 Postman/curl 测
```

这样你能顺便把这个 Go 项目的结构真正吃下来，而不是我给你一个和你项目架构完全不同的 Gin 示例。
